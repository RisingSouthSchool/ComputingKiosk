            📦 Instance Factory API
          

          
Used to spawn 3D object instances into the scene.

          

            
Instance.spawn(templateName, x, y, z)

            
Spawns a new 3D instance. Built-in templates: "RobotCar", "Cube", or your saved Designer templates. Returns instance table object.

          

        


        
        

          

            ⚙️ Instance & Part Methods
          

          
Methods available on spawned 3D instances and sub-parts:

          

            

              
inst:move(dx, dy, dz)

              
Translates the instance along local axes by (dx, dy, dz).

            

            

              
inst:rotate(rx, ry, rz)

              
Rotates the instance by rx, ry, rz degrees around X, Y, Z axes.

            

            

              
inst:getPosition() & inst:getRotation()

              
Returns 3 values: x, y, z position or rx, ry, rz rotation angles in degrees.

            

            

              
inst:getData()

              
Returns a Lua table containing instance metadata: { id, position = {x,y,z}, rotation = {x,y,z} }.

            

            

              
inst:GetPart(partName)

              
Retrieves a named sub-part object (e.g. car:GetPart("Cabin")).

            

            

              
part:getPosition() & part:getWorldPosition()

              
Returns local or world x, y, z coordinates of a sub-part.

            

            

              
part:getData()

              
Returns a table with sub-part properties: { name, position, worldPosition, rotation, color }.

            

            

              
inst.OnClicked:Connect(function() ... end)

              
Binds a callback function that runs when the user clicks the 3D object in the viewport.

            🎮 Input & Timing Utilities
          

          

            

              
UserInputService.isKeyDown(keyString)

              
Returns boolean whether a key is currently held down. Supports "w", "a", "s", "d", "ArrowUp", "Space", "Shift", "i", "j", "k", "l", etc.

            

            

              
task.wait(seconds)

              
Yields execution of the Lua thread for specified duration (in seconds). Ideal inside while true do loops.

            

            

              
print(...)

              
Outputs values or text to the Output Terminal log.
